# Программный комплекс для сбора и анализа вакансий с hh.ru

## Общее описание

Данный программный комплекс разработан в рамках выполнения курсовой работы по дисциплине «Проект (практикум) по экономической социологии» на тему «Практики российских IT-компаний по привлечению, адаптации и удержанию сотрудников поколения Z». Комплекс представляет собой инструментарий для автоматизированного сбора и предварительной обработки данных о вакансиях уровня "Junior" и "Стажер" с портала hh.ru.

Программное обеспечение реализует первый этап исследовательской методологии — количественный анализ декларируемых условий труда в IT-вакансиях, направленных на привлечение молодых специалистов (поколения Z). Этот этап является фундаментальным для последующего качественного исследования, включающего интервью с HR-специалистами и тим-лидерами.


## Функциональное назначение программного комплекса

Программный комплекс решает конкретную исследовательскую задачу: **«Выявить декларируемые в IT-вакансиях условия трудоустройства, направленные на привлечение молодежи (количественная; парсинг + контент-анализ)»**.

Для реализации этой задачи система выполняет следующие функции:

### 1. Автоматизированный сбор данных через API hh.ru
- Получение информации о вакансиях конкретной компании по ее идентификатору
- Параметризация запросов (количество вакансий на странице, фильтрация)
- Обработка HTTP-запросов с учетом ограничений публичного API

### 2. Интеллектуальная фильтрация вакансий
- Выделение позиций, релевантных для начинающих специалистов (стажеров, джуниоров)
- Исключение ложных срабатываний через использование контекстуальных регулярных выражений

### 3. Структурирование и нормализация данных
- Преобразование сложных JSON-структур в плоскую табличную форму
- Обработка разнотипных данных (словари, списки, простые значения)
- Форматирование числовых данных (зарплата с разделителями разрядов)
- Устранение дубликатов на основе уникальных идентификаторов вакансий

### 4. Экспорт в аналитически удобные форматы
- Сохранение промежуточных данных в JSON для верификации
- Экспорт финальных результатов в CSV для последующего статистического анализа
- Поддержка кириллической кодировки для корректного отображения русскоязычного контента

## Техническая архитектура

Система построена по двухуровневой архитектуре:

**Уровень 1: Сбор данных (Bash-скрипт)**
Использует стандартные утилиты командной строки:
- `curl` для выполнения HTTP-запросов к API hh.ru
- `jq` для обработки и фильтрации JSON-данных
- Регулярные выражения для лингвистического анализа названий вакансий

**Уровень 2: Обработка данных (Python-скрипт)**
Использует библиотеки Python:
- `pandas` для работы с табличными данными и экспорта в CSV
- Стандартную библиотеку `json` для чтения JSON-файлов
- Кастомную логику для обработки сложных структур данных API hh.ru

## Критерии отбора вакансий

Отбор вакансий осуществляется по двум основным критериям:

1. **Формальный критерий**: наличие флага `internship: true` в данных API, указывающего на официальную программу стажировки.

2. **Лексический критерий**: наличие в названии вакансии ключевых терминов, обозначающих начальный уровень позиции:
   - "стажер" и производные
   - "стажировка" 
   - "junior" 
   - "джуниор"
   - "trainee"
   - "intern"

Для исключения ложных срабатываний используется контекстуальное регулярное выражение, учитывающее границы слов.

## Методологические особенности реализации

### Обработка разнородных данных API
API hh.ru возвращает данные в сложно структурированном формате, где одни и те же поля могут содержать данные разных типов (словарь, список словарей, строковое значение). Вспомогательная функция `get_field_value` реализует рекурсивную логику обработки этих структур, обеспечивая устойчивость скрипта к изменениям в формате данных API.

### Устранение дубликатов
В процессе сбора данных возможны случаи дублирования вакансий. Для обеспечения чистоты данных для последующего статистического анализа реализован механизм отслеживания уникальных идентификаторов вакансий через множество `seen_ids`, что обеспечивает константную сложность проверки на дублирование.

### Поддержка кириллицы
Учитывая, что анализ ведется на русскоязычных данных, все компоненты системы настроены на корректную обработку кириллицы:
- Bash-скрипт использует UTF-8 кодировку
- Python-скрипт указывает кодировку `utf-8` при экспорте CSV
- Регулярные выражения поддерживают как кириллические, так и латинские символы

## Использование в исследовательском процессе

Данный программный комплекс является первым этапом в смешанном последовательном дизайне исследования. Полученные данные (CSV-файл с вакансиями) служат:

1. **Эмпирической базой** для контент-анализа декларируемых HR-практик
2. **Основой для триангуляции** — сравнения декларируемых условий с фактически реализуемыми практиками

## Ограничения и этические аспекты

### Технические ограничения
1. **Ограничения API hh.ru**: не более 100 вакансий за один запрос, лимиты на количество запросов (можно выставить иные настройки)
2. **Поверхностный сбор**: скрипт анализирует только первую страницу результатов (можно выставить иные настройки)
3. **Зависимость от структуры API**: изменения в формате данных hh.ru могут нарушить работу скрипта

### Методологические ограничения
1. **Декларируемые vs фактические условия**: скрипт анализирует только то, что компании заявляют в вакансиях, что может расходиться с реальными условиями труда
2. **Лексический анализ**: возможны как ложные срабатывания, так и пропуски релевантных вакансий
